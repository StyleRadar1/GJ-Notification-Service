# Resumen Oficial de Endpoints y Requerimientos (`ms-Notifications` · Puerto `8300`)
**Proyecto:** StyleRadar · **Equipo:** Guatoque Jiraguas (GJ) · **Paquete 3:** Notificaciones y Chat · **Fecha:** 18 de noviembre de 2026

---

## 1. Estado del Contrato y Alineación con el Swagger de QA (`/v3/api-docs`)

* **URL de QA (Swagger encendido):** `https://styleradar-notificaciones-qa.azurewebsites.net/swagger-ui/index.html` (`https://styleradar-notificaciones-qa.azurewebsites.net/v3/api-docs`)
* **URL de PROD (Swagger apagado por seguridad con `SWAGGER_ENABLED=false`):** `https://styleradar-notificaciones-prod.azurewebsites.net`
* **Idioma del Swagger / OpenAPI:** **100 % en inglés** (títulos, resúmenes, descripciones de operaciones y esquemas), verificado automáticamente por `ContratoSwaggerAlineadoTest`. Los mensajes de error en tiempo de ejecución (`detail`, `mensaje`) se mantienen en español.
* **Seguridad y Límite de Uso:** Todos los endpoints bajo `/api/v1/users/{id}/...` exigen JWT HS256 en `Authorization: Bearer <token>` (excepto `/notifications/stream`, que acepta `?ticket=<ticket>` de 60 s emitido por `POST /notifications/stream-ticket`). El `{id}` de la ruta debe coincidir con el `userId`/`sub` del token (o `me`), salvo rol `ROLE_ADMIN_STYLERADAR`; si no coincide, responde `403 Forbidden` (`code: ACCESS_DENIED`). Límite global: **120 solicitudes/minuto por usuario** (`429 Too Many Requests` con cabecera `Retry-After` y `code: RATE_LIMITED`).

## 3. Tabla Oficial de Códigos de Error Estables (`code` · `CodigoError`)

Todas las respuestas de error utilizan `application/problem+json` (`ProblemDetail`, RFC 7807) con `type: "about:blank"`, `title`, `status`, `detail`, `instance`, `mensaje`, `timestamp`, un **`code` estable** y, en los `400` de validación de campos, el mapa `errors` por campo. El frontend decide qué mensaje mostrar a partir de `code`:

| Código Estable (`code`) | Estado HTTP | Cuándo se devuelve |
| :--- | :---: | :--- |
| `VALIDATION_ERROR` | `400` | Fallo de validación `@Valid` o restricciones de parámetros (`page < 0`, `size < 1`, `size > 100`, `itemId` vacío en `/alerts/check`). Incluye `errors` por campo. |
| `INVALID_PARAMETER` | `400` | Parámetro de ruta o query con tipo o valor de enum inválido (ej. `type` desconocido en preferencias o `page=abc`). |
| `MALFORMED_REQUEST` | `400` | Cuerpo JSON malformado o con valor de enum inválido (`canal` o `tipoAlerta` desconocido). |
| `UNAUTHENTICATED` | `401` | Token JWT o ticket SSE ausente, vencido, con firma inválida, JWT de sesión pasado en la URL o ticket SSE usado fuera del stream. |
| `ACCESS_DENIED` | `403` | El `{id}` de la ruta no coincide con el usuario del token, o intenta operar sobre una alerta, notificación o búsqueda guardada ajena. |
| `ALERT_NOT_FOUND` | `404` | La alerta solicitada no existe al desactivar o reactivar. |
| `NOTIFICATION_NOT_FOUND` | `404` | La notificación solicitada no existe al marcarla como leída. |
| `NOT_FOUND` | `404` | Recurso de dominio no encontrado (genérico). |
| `ROUTE_NOT_FOUND` | `404` | Ruta HTTP inexistente en el microservicio. |
| `ALERT_ALREADY_ACTIVE` | `409` | Ya existe una alerta `ACTIVA` para el mismo usuario, prenda (`itemId`) y talla (`tallaObjetivo`), o para la misma búsqueda guardada (`busquedaGuardadaId`). |
| `CONFLICT` | `409` | Conflicto de estado o unicidad concurrente. |
| `ITEM_HAS_STOCK` | `422` | La prenda consultada en `ms-ItemCatalog` actualmente tiene unidades disponibles (el front muestra «Esta prenda ya tiene unidades» y opción de reservar). |
| `ITEM_NOT_FOUND` | `422` | La prenda indicada no existe en `ms-ItemCatalog` (404 desde catálogo al validar disponibilidad). |
| `ACCOUNT_NOT_ALLOWED` | `422` | La cuenta del usuario se encuentra en estado `INACTIVO`, `BLOQUEADO` o `SUSPENDIDO` y no puede registrar ni reactivar alertas. |
| `SAVED_SEARCH_NOT_AVAILABLE` | `422` | La búsqueda guardada indicada no existe en la copia local sincronizada o no se encuentra activa. |
| `INVALID_ALERT` | `422` | Combinación inválida en la alerta (falta `itemId` en `ITEM_AGOTADO`, falta `busquedaGuardadaId` en `BUSQUEDA_GUARDADA`, o se enviaron ambos simultáneamente). |
| `BUSINESS_RULE_VIOLATION` | `422` | Otra violación de regla de negocio del dominio. |
| `RATE_LIMITED` | `429` | El usuario superó el límite de 120 solicitudes por minuto (incluye cabecera `Retry-After`). |
| `CATALOG_UNAVAILABLE` | `503` | `ms-ItemCatalog` no responde o falla la conexión al verificar disponibilidad de la prenda. |
| `EXTERNAL_SERVICE_UNAVAILABLE` | `503` | Fallo de comunicación con otro servicio externo requerido. |
| `INTERNAL_ERROR` | `500` | Error interno inesperado no controlado. |
